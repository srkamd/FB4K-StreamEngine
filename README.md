## 🌟 Key Features

- ⚡ **Facebook Video Downloader:** Instant parsing of public posts with clean HD/SD direct download streams.
- 🎬 **Facebook Reels Downloader:** Optimized 9:16 vertical video support with instant preview and download options.
- 🎵 **Facebook to MP3 Audio:** Client-friendly audio demuxing and high-quality 320kbps MP3 extraction.
- 📑 **10-Link Bulk Archive:** Personal archiving queue allowing up to 10 public links to be fetched simultaneously.
- 🎨 **Lightweight & 100% Mobile Responsive:** Custom mobile-first theme engineered for sub-second page loads across phones, tablets, and 4K displays.
- 🛡️ **Privacy-First & Fully Compliant:** Zero permanent video storage, in-memory stream piping (`axiosClient`), rolling RAM log buffer (50 logs max), and prominent creator copyright notices.
- 📚 **18 In-Depth Publisher Guides:** Comprehensive knowledge base and technical blog written by Shahrukh Ahmad (SRK AMD) covering video encoding, Fair Use ethics, and official backup methods.

## 💻 Tech Stack

- **Backend:** Node.js, Express.js
- **Media Engine:** In-memory stream piping, dynamic FFmpeg integration
- **Frontend:** Vanilla HTML5, CSS3 (Modern Light Tokens), JavaScript (Modular & Zero-Dependency)
- **Extension:** Google Chrome Manifest V3 Web Extension

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v16 or higher)
- npm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/srkamd/fb4kdownloader.git
   cd fb4kdownloader
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local server:**
   ```bash
   node server.js
   ```

4. **Open in browser:**
   ```
   http://localhost:3000
   ```
